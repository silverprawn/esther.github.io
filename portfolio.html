CC5. Accessing data: (1) API, (2) Scraper

(1) API: a live chart

How the API works

  • API: World Bank Indicators API (version 2). Free, no API key needed, and it allows browser requests (no CORS problem).
  • Base URL: https://api.worldbank.org/v2/country/{countries}/indicator/{indicator}
  • Elements needed to call data:
    • {countries}: ISO-3 country codes, joined with ; (here mys;sgp;tha;idn).
    • {indicator}: the series code from data.worldbank.org (here SP.DYN.TFRT.IN, total fertility rate).
    • ?format=json: return JSON instead of the default XML.
    • &per_page=1000: return all rows on one page (the default of 50 would cut off older years).
  • Data returned: JSON, nested as a list of two parts: [metadata, data]. The metadata gives page counts and the last update date; the data is one record per country-year with date, value and a nested country.value name. Within the data part it is tidy (long form). Vega-Lite reads it with "format": {"property": "1"}. Years without data are null and are filtered out.
  • Full URL used: https://api.worldbank.org/v2/country/mys;sgp;tha;idn/indicator/SP.DYN.TFRT.IN?format=json&per_page=1000
